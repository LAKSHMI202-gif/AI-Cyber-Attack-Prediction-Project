# AI Cyber Attack Prediction Project

## 📌 Project Overview

The AI Cyber Attack Prediction Project is a machine learning-based cybersecurity application designed to analyze network data and predict potential cyber attacks.

The system uses Python, machine learning algorithms, and a dataset of network-related information to support automated cyber attack prediction.

## 🎯 Objectives

- Detect potential cyber attacks using machine learning.
- Analyze network-related data.
- Preprocess the dataset for machine learning.
- Train a prediction model.
- Provide predictions through a Python application.
- Demonstrate the use of Artificial Intelligence in cybersecurity.

## 🛠️ Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML/CSS
- CSV Dataset
